# ADR-0007: The name is ionhomie, on GitHub as syncytium2/ionhomie

## Status

Accepted, 2026-10-20, by Tony: "lets go with ionhomie … create the repo on github using ionhomie."

## Context

`ion-homeostasis` was a working folder name ([naming.md](../naming.md) holds the researched
candidates). Tony chose a name not on that list.

## Decision

- The project, the repository and the folder are `ionhomie`.
- The repository is `syncytium2/ionhomie`, **public**, like the sibling teaching tools
  (`gaba_excites`, `colonel_kernel`, `ml2dl`), under the MIT license.
- The site, when deployed, is at `ionhomie.tonydefazio.com` (proposed by Claude, following
  `gaba.tonydefazio.com`; Tony has not ruled on the subdomain).

## Consequences

- `naming.md` stays as the record of the search; its candidates are not used.
- Deploying creates a DNS record for the subdomain; that step waits for Tony's go-ahead
  (MILESTONES).

*Carried out 2026-10-20: Tony said "deploy"; the site is live at `ionhomie.tonydefazio.com`, the subdomain
proposed above.*
